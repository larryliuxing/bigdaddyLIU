# 公会助手

游戏公会身份登录系统，已实现拍卖与排行榜模块。

## 功能

- **身份选择登录**：选择成员昵称，首次设置密码（至少 6 位），之后需验证密码
- **功能首页**：拍卖 / BOSS 计时器 / 排行榜入口
- **拍卖模块**
  - 管理员设置开始时间（默认 15:00）与时长（默认 30 分钟）
  - 提前添加拍品：名称、品质、起拍价、加价、图片粘贴
  - 分红成员：成员名单点选 + 粘贴游戏参与者截图 OCR 识别（未识别的可手动补选）
  - 拍卖大厅：动态、出价、匿名模式、历史、分红统计
  - 结束后自动计算分红，支持临时加人与金额调整
- **排行榜模块**
  - 玩家上传/粘贴本人战力截图，OCR 识别角色名与战斗力
  - 截图名字必须与当前登录账号一致，否则拒绝上榜
  - 按战力排序；显示平均战力与合格线（平均 × 85%），低于合格线名字标红
- **管理员后台**：右上角齿轮进入，管理成员；也可进入拍卖管理

## 默认管理员

- 账号：`admin`
- 密码：`admin123`

可在 `.env.local` 中通过 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 修改（仅在首次初始化数据库时生效）。

## 开发

```bash
cp .env.example .env.local
npm install
npm run dev
```

访问 http://localhost:3000

## 技术栈

- Next.js (App Router) + TypeScript + Tailwind CSS
- SQLite (`better-sqlite3`) 本地存储
- JWT Cookie Session + bcrypt 密码哈希
- Tesseract.js 客户端 OCR
